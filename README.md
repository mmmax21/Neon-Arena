# Neon Arena

A neon top-down arena shooter made with Godot 4 (GL Compatibility). All visuals are drawn in code and all sound effects are synthesized at runtime — no external assets.

## Controls

| Action | Input |
|---|---|
| Move | WASD / Arrow keys |
| Aim | Mouse |
| Fire | Hold Left Click |
| Dash (brief invincibility) | Space / Shift / Right Click |
| Pause | P / Esc |
| Retry | R or Click (on game over) |

## Features

- Endless waves with escalating difficulty
- Enemies: chasers, strafing shooters, armored tanks, and a boss (CORE WARDEN) every 5 waves
- Pickups: heal and rapid-fire (triple shot)
- Combo score multiplier, saved best score
- Particles, screen shake, dash afterimages, spawn warnings

## Run

Open the folder in Godot 4.3+ and press Play, or export with the included **Web** preset.
