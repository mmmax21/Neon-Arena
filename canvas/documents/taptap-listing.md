## H5 包体与在线功能

- **包体**：`.ohmygame/build/neon-arena-taptap.zip`，约 12 MB（上限 300 MB）。解压后只有一个文件夹 `neon-arena/`，里面放 `index.html`。由导出预设「TapTap」生成，页面里已声明横屏。
- **排行榜和联机保留**，和网页版共用同一台服务器，数据互通：
  - 服务器已允许 TapTap 的网页域名访问。
  - 玩家名改为随机生成（如「霓虹猎手42」），点名字按钮换一个，不让玩家自由输入。服务器对名字另做一层过滤（网址、联系方式、屏蔽词），满足平台的文字过滤要求。
  - 联机输房间号用游戏内的屏幕键盘，不依赖浏览器弹窗。
- **上线前要做**：
  1. 部署服务器更新（`server` 目录下运行 `npm run deploy`），不部署的话，TapTap 版连不上。
  2. 国内访问 `workers.dev` 不稳定。建议给服务器绑定一个已备案的自有域名，填进 `scripts/net.gd` 的 `API_URL_TAPTAP`，然后重新导出。步骤见 `server/README.md` 的「TapTap 版」一节。
  3. 上传后，用自测二维码在手机上实测排行榜和联机。连不上的话，按 README 用 `wrangler tail` 找出被拒的域名并加入白名单。
