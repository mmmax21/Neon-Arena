# Neon Arena 游戏设计文档

> 状态：可玩原型（v0.3：中英双语、升级间隔、构筑图标）· 引擎：Godot 4.3+（GL Compatibility）· 平台：网页（桌面浏览器）
> 在线试玩：https://mmmax21.github.io/Neon-Arena/（版本选择页）· 源码：https://github.com/mmmax21/Neon-Arena
> 版本：**v2.0**（本文档描述的版本，`main` 分支 / `v2.0` 标签，试玩 /v2/）· v1.0 初版（`v1` 分支 / `v1.0` 标签，试玩 /v1/）
>
> 本文档记录**当前已实现**的设计与数值。标注「规划」的内容尚未实现。

## 1. 概述

**一句话**：在一个霓虹网格竞技场里，驾驶一艘箭头形战机，选一把主武器，每清一波就从三张升级卡里挑一张，用冲刺穿越弹幕，抵挡一波比一波凶的几何体敌人，并冲击最高分。

- **类型**：俯视角竞技场射击（Twin-stick 式操作，键鼠），带 Roguelite 式的单局构筑
- **单局时长**：3–10 分钟，失败即重开
- **目标玩家**：喜欢短局、高节奏、追分的动作游戏玩家
- **胜负**：没有通关，生命值归零时结算分数

## 2. 设计支柱

1. **一眼就懂**：纯几何图形 + 高对比霓虹配色。每种敌人靠形状和颜色区分，不需要教程。
2. **爽快反馈**：每一发子弹都有枪口火花、命中火花、击退、震屏和音效。击杀会出现爆炸粒子、扩散光环和浮动分数。
3. **冲刺是核心技巧**：冲刺带短暂无敌，玩家能主动穿过弹幕、激光和敌群。高手和新手的差距主要体现在这里；冲刺也有专属升级。
4. **每局都不一样**：主武器 × 升级卡组合出不同的打法（例如「弹射 + 追踪」的脉冲枪、「冲击波 + 火焰冲刺」的近战流）。
5. **零外部资源**：所有画面都用代码绘制，所有音效都在运行时合成，加载快、修改方便。

## 3. 核心循环

```
选主武器 → 波次开始 → 敌人在预警圈处陆续刷出 → 移动、射击、冲刺求生
   → 击杀得分、累积连击、捡道具 → 清空本波 → 清波奖励 →（每 3 波）三选一升级 → 下一波（更难）
                                         ↘ 生命归零 → 结算 → R 同武器重开 / 点击重新选武器
```

## 4. 操作

| 动作 | 输入 |
|---|---|
| 移动 | WASD / 方向键（8 方向，带加速惯性） |
| 瞄准 | 鼠标（系统光标隐藏，显示自定义准星） |
| 射击 | 按住鼠标左键连射 |
| 冲刺 | 空格 / Shift / 鼠标右键（按下时触发） |
| 选卡（武器 / 升级） | 点击卡片，或按 1 / 2 / 3 |
| 切换语言 | 标题页右上角点「English / 中文」，或任何时候按 L |
| 暂停 | P / Esc（窗口失去焦点时自动暂停；选武器界面按 Esc 返回标题） |
| 开始 / 重开 | 标题页点击或回车进入选武器；结算页按 R 用同一把武器重开，点击则重新选武器 |

## 5. 玩家

| 属性 | 数值 |
|---|---|
| 生命 | 6 格 |
| 移动速度 | 290 px/s（插值加速，系数 12） |
| 碰撞半径 | 15 px（被子弹判定时用 70%，即约 10.5 px，判定偏宽松） |
| 受伤无敌 | 1.1 秒（期间闪烁），受伤会清空连击 |

**冲刺**：持续 0.16 秒，速度 860 px/s，冷却 1.0 秒（可被升级缩短），冲刺期间及之后 0.08 秒无敌。方向优先取移动方向，不移动时取瞄准方向。会留下残影；飞船外圈的环形进度条显示冷却。

**射击输入**：按住左键连射；一次很短的点击（按下和松开落在同一帧）也会被记下，在冷却好后补射一发。

## 5.1 主武器

开局在三张武器卡里选一把，整局不换。武器的颜色也是它子弹 / 光束的颜色。

| 武器 | 定位 | 射击间隔 | 每次射击 | 伤害 | 特点 |
|---|---|---|---|---|---|
| 脉冲 PULSE | 均衡 | 0.13 秒 | 1 发，速度 780，存在 1.4 秒，散布 ±0.04 | 1 | 原来的默认武器，后坐力最小 |
| 霰弹 SCATTER | 近距离 | 0.5 秒 | 5 颗弹丸，扇形 0.5 弧度，速度 620–760，只存在 0.42 秒 | 每颗 1 | 贴脸爆发高，射程约 300 px，后坐力大 |
| 激光 LASER | 穿透 | 0.38 秒 | 一道瞬发光束，打到柱子 / 墙 / 长蛇身体为止 | 2.2 | 穿透光束上的所有敌人，闪避者躲不开它 |

**多重射击**对不同武器的效果：脉冲每级多 1 发（间隔 0.11 弧度）；霰弹每级多 2 颗弹丸、扇面加宽 0.08；激光每级多 1 道光束（间隔 0.09 弧度）。

## 5.2 升级卡（三选一）

**发放间隔：每清完 3 波发一次**（第 3、6、9……波之后）。顶部波次下方有「升级 ◆◆◇」进度条，显示离下一张卡还差几波。

选 3 波而不是 5 波或 8 波的理由：
- 一局一般打 8–15 波，每 3 波一张卡能拿到 3–5 张，足够凑出一套有特色的组合；每 5 波只有 1–3 张，每 8 波只有 1–2 张，14 种升级大部分根本见不到，三选一也就失去意义。
- 每 3 波的节奏和 Boss（每 5 波）错开：Boss 战前后都会有一次变强的机会，不会出现连续很多波没有成长的空档。
- 卡变少后，每次选择更有分量，也不会像每波都发那样频繁打断战斗。

间隔由 `main.gd` 里的 `UPGRADE_EVERY` 常量控制，调平衡时只改这一个数。

清完到达间隔的那一波后，结算奖励后约 1.1 秒弹出升级界面，游戏暂停，从 3 张卡里选 1 张。选完后休整 1.4 秒开始下一波；其他波次之间照常休整 2.6 秒。界面打开后 0.5 秒内不接受输入，防止连射时误点。

**分类**：升级分成 4 类，每类一种颜色，卡片顶部、HUD 图标边框和悬停提示都用这个颜色：

| 类别 | 颜色 | 包含 |
|---|---|---|
| 火力 FIREPOWER | 橙红 | 速射、多重射击、威力、暴击 |
| 弹道 BALLISTICS | 黄 | 穿透、弹射、追踪、碎裂 |
| 冲刺 DASH | 青 | 火焰冲刺、冲击波、快速冲刺 |
| 生存 SURVIVAL | 绿 | 活力、屏障、磁铁（以及修复卡） |

### 6.1 精英敌人

从第 7 波开始，追击者、射手、坦克、分裂者、闪避者、哨塔、布雷者有 min(5% × (w − 6), 35%) 的概率以精英身份出现：生命 ×1.5、分值 ×2、掉落率 ×4，刷怪预警圈变成金色，身上有一圈旋转光环。每个精英带一个词缀：

| 词缀 | 光环颜色 | 效果 |
|---|---|---|
| 护盾 Shield | 浅蓝 | 额外 3 + ⌊w/3⌋ 点护盾，先扣护盾再扣血（显示为蓝色进度环），护盾期间几乎不被击退 |
| 疾速 Haste | 黄 | 移速 ×1.45；闪避者的闪避冷却缩短到 0.5 秒 |
| 爆裂 Volatile | 橙 | 死亡时向四周射出 10 发子弹 |

### 6.2 Boss：CORE WARDEN

- 在第 5、15、25……波出现（和 VOID WEAVER 轮流），排在该波刷怪队列的最前面。刷出时预警 1.4 秒，并伴随震屏。
- 移动：距离玩家超过 220 px 时逼近，否则缓慢后退。
- **攻击循环**依次为：环形弹幕 → 扇形散射 → 环形弹幕，然后重复。
  - 环形弹幕：16 发（狂暴后 22 发），速度 210，整体随 Boss 的旋转角偏移，每次缺口位置不同。
  - 扇形散射：朝玩家打 7 发，间隔 0.14 弧度，速度 330。
  - 攻击间隔：环形 1.5 秒 / 散射 1.1 秒；狂暴后分别缩短到 1.1 / 0.8 秒。
- **狂暴阶段**：生命低于 50% 时，旋转加快，弹幕更密、更快。
- 屏幕底部显示 Boss 名字和血条。击败后必定掉落一个修复和一个超载道具。

### 6.3 Boss：VOID WEAVER

- 在第 10、20、30……波出现。距离玩家超过 300 px 时逼近，否则后退。
- **攻击循环**依次为：旋转激光 → 螺旋弹幕 → 召唤，每次攻击之间停顿约 0.8–1.2 秒。
  - 旋转激光：先显示 3 道（狂暴后 4 道）闪烁的预警线 1.1 秒，然后变成实体激光持续 2.6 秒，以每秒 0.7（狂暴后 1.0）弧度旋转，每次换方向。Boss 此时站定。激光被柱子挡住，可以躲在柱子后面，或者冲刺穿过。
  - 螺旋弹幕：2.2 秒内每 0.08 秒（狂暴后 0.06 秒）射出 2 条（狂暴后 3 条）旋转的子弹臂，速度 220。
  - 召唤：在身边召唤 4 个（狂暴后 6 个）小怪；场上小怪已有 10 个以上时跳过。
- **狂暴阶段**：生命低于 50% 时触发，效果如上。
- 击败后同样掉落一个修复和一个超载道具。

## 7. 波次系统

| 参数 | 规则 |
|---|---|
| 每波敌人数 | 4 + 2w（Boss 波另加 1 个 Boss） |
| 敌人种类 | 按权重从已解锁的敌人里随机抽：追击者 10、射手 4、分裂者 3、坦克 2、闪避者 3、哨塔 2、布雷者 2、长蛇 1 |
| 数量上限 | 每波坦克 ≤ 2 + ⌊w/3⌋，哨塔 ≤ 1 + ⌊w/5⌋，布雷者 ≤ 1 + ⌊w/6⌋，长蛇 ≤ 1 + ⌊w/8⌋；超出的换成追击者 |
| 精英 | 见 6.1 |
| Boss | w 是 5 的倍数时出现，CORE WARDEN 和 VOID WEAVER 轮流 |
| 刷怪间隔 | max(0.22, 0.85 − 0.05w) 秒，逐只刷出 |
| 刷怪预警 | 先出现闪烁的红色十字圈，0.9 秒后敌人出现（Boss 为 1.4 秒） |
| 刷怪位置 | 场地内随机，距玩家至少 300 px、离柱子边缘至少 60 px |
| 清波条件 | 刷怪队列、预警圈、存活敌人（地雷除外）全部清空 |
| 清波时 | 加 100 × w 分；场上的敌方子弹和地雷全部消散 |
| 节奏 | 开局休整 1.2 秒；普通清波后休整 2.6 秒；每第 3 波清波 → 1.1 秒 → 升级界面（暂停）→ 选完后 1.4 秒 → 下一波 |

波次无上限。难度主要靠四点逐步提升：敌人数量增加、刷怪更快、敌人更耐打更快、新敌人种类和精英逐渐加入。玩家这边则靠每波一张升级卡变强。

| 道具 | 外观 | 掉落概率 | 效果 |
|---|---|---|---|
| 修复 | 绿色十字 | 7% | 回复 2 格生命（不超过上限） |

## 9. 计分

- **击杀得分** = 敌人分值 × 连击倍率。
- **连击**：每次击杀 +1，2.5 秒内没有新的击杀就清零，受伤也清零。
- **连击倍率** = 1 + min(连击 − 1, 20) × 0.1，最高 3 倍。
- **清波奖励**：100 × 波次。
- **最高分**保存在本地（`user://best.save`，网页版存在浏览器存储里）。

## 10. 竞技场

- 可活动区域 1220 × 660（画面 1280 × 720，四周留 30 px 边框），带 40 px 网格底纹和发光边框。
- 6 根圆柱掩体，左右对称：四角 4 根大柱（半径 42），上下中线各 1 根小柱（半径 28）。场地中心留空，是玩家的出生点。
- 柱子会挡住玩家、敌人和所有子弹（子弹撞到会溅出火花）。

## 11. 界面与流程

**状态**：标题 → 选武器 → 游戏中 ⇄ 暂停 / 升级界面 → 结算 →（R）游戏中 /（点击）选武器

- **标题页**：游戏名、操作说明、闪烁的「点击开始」、历史最高分，右上角是「English / 中文」语言切换按钮。
- **选武器 / 升级界面**：3 张竖卡居中排列，鼠标悬停时卡片放大、描边变亮；卡上有类别、名称、说明、等级和对应的数字键。
- **游戏中 HUD**：
  - 左上：生命格（剩 2 格以下时变红闪烁）、冲刺冷却条，下面是**构筑图标栏**：第一格是当前武器，后面按 火力 → 弹道 → 冲刺 → 生存 的顺序排列已拥有的升级，每行 6 个，边框是类别颜色，右下角数字是等级（只能拿一级的升级不显示数字）。鼠标悬停在图标上，会在图标栏右侧显示名称、等级 / 上限、类别和效果说明。再往下是超载剩余时间、屏障充能倒计时。
  - 顶部中间：当前波次，以及「升级 ◆◆◇」进度条。
  - 右上：分数、最高分、连击数。
  - 底部：Boss 名字和血条（仅 Boss 存活时显示）。
  - 屏幕中间：波次开始 / 清波 / 获得升级的提示，带放大入场效果（只在游戏中和暂停时显示，不会盖住卡片和结算页）。
- **结算页**：「游戏结束」、本局分数、是否刷新最高分、波次 / 击杀数 / 存活时间，以及居中的本局构筑图标栏（同样可以悬停查看）。0.8 秒后才接受点击，防止误触。

### 11.1 语言

- 支持英文和简体中文，所有界面文字、卡片、提示和 Boss 名都有两种语言（核心守卫 CORE WARDEN、虚空织者 VOID WEAVER）。游戏标题「NEON ARENA」两种语言都保持英文。
- 首次打开时跟随系统 / 浏览器语言（中文系统默认中文，其他默认英文）；之后记住玩家的选择（`user://settings.cfg`，网页版存在浏览器存储里）。
- 切换：标题页点按钮，或任何界面按 L（暂停时也可以）。已经出现在屏幕上的提示文字保留原语言直到消失。
- 中文使用内置的 Noto Sans SC Medium 字体（SIL Open Font License，许可证在 `fonts/OFL.txt`），只保留游戏用到的约 320 个字符，约 90 KB；英文继续用 Godot 默认字体。

## 12. 美术风格

- **基调**：深蓝黑背景 + 高饱和霓虹描边，几何矢量风。
- **颜色分工**：
  - 玩家：青色 #40E6FF
  - 玩家武器：脉冲暖黄、霰弹橙黄、激光青白
  - 追击者红、射手紫、坦克橙、分裂者 / 小怪黄绿、闪避者蓝、哨塔粉、布雷者 / 地雷白、长蛇金；Boss：CORE WARDEN 洋红、VOID WEAVER 紫蓝
  - 敌方子弹：紫色 / 粉色 / 橙色圆弹，带白色核心，和玩家的拖尾子弹明显区分
  - 敌方激光：先闪一条细预警线，再变成带白芯的粗光束；玩家激光是青白色的瞬间闪光
  - 精英光环：护盾浅蓝、疾速黄、爆裂橙
  - 道具：绿、黄
- **特效**：粒子爆炸、扩散光环、冲刺残影、枪口火花、浮动分数、受击白闪、火焰冲刺的火焰轨迹、地雷爆炸范围圈、按事件强度分级的震屏（上限 26 px）。
- 所有图形都用 Godot 的 `_draw()` 实时绘制，不使用贴图。

## 13. 音效

全部由 `sfx.gd` 在启动时用方波、锯齿波、正弦波加噪声合成为 22.05 kHz 的 16 位单声道音频。用 16 个播放器轮流播放，每次播放音高随机 ±8%；高频音效有最小播放间隔，防止叠加后刺耳。

| 事件 | 音色 |
|---|---|
| 射击 | 短促下滑方波 |
| 敌人射击 | 锯齿下滑 |
| 命中 | 噪声方波 |
| 爆炸 / 大爆炸 | 低频噪声，0.28 秒 / 0.7 秒 |
| 受伤 | 锯齿下滑 |
| 拾取 / 开局 | 上扬正弦 |
| 冲刺 | 噪声上扬 |
| 刷怪预警 | 轻微高音 |
| 清波 | 上扬方波 |
| 霰弹 / 激光 | 噪声方波爆响 / 高音锯齿下滑 |
| 敌方激光蓄力 / 发射 | 上扬正弦 / 低沉锯齿 |
| 屏障抵挡、精英护盾破碎 | 下滑正弦 |
| 地雷引信 | 短促高音方波 |
| 升级界面弹出 | 上扬方波 |
| 冲击波 | 低沉噪声正弦 |

暂无背景音乐。

## 14. 技术实现

| 文件 | 职责 |
|---|---|
| `main.gd` | 游戏状态机、武器和升级数据表、波次刷怪表、升级抽卡、全部碰撞检测（手写圆形判定和射线检测，不用物理引擎）、激光 / 爆炸 / 冲击波 / 火焰、得分、存档、竞技场绘制 |
| `scripts/player.gd` | 输入、移动、冲刺、三种武器的射击、升级等级和由此算出的属性、屏障、受伤 |
| `scripts/enemy.gd` | 10 种普通敌人和 2 个 Boss 的行为、精英词缀、外形和激光绘制 |
| `scripts/bullet.gd` | 子弹的移动和绘制，以及穿透 / 弹射 / 追踪 / 碎裂状态 |
| `scripts/pickup.gd` | 道具 |
| `scripts/fx.gd` | 粒子、光环、光束、浮动文字、火焰轨迹、刷怪预警（粒子上限 900） |
| `scripts/hud.gd` | HUD、构筑图标栏和悬停提示、升级进度条、选卡界面、语言按钮、各界面覆盖层、准星 |
| `scripts/i18n.gd` | 全部中英文文本表；`main.t(key)` 按当前语言取文字 |
| `scripts/icons.gd` | 武器和升级的矢量图标绘制 |
| `fonts/` | 中文字体子集和它的 OFL 许可证 |
| `tools/subset_font.py` | 重新生成中文字体子集（`tools/` 有 `.gdignore`，不会被打进游戏）。在 `i18n.gd` 里加了新汉字后要运行一次 |
| `scripts/sfx.gd` | 程序合成音效 |

- 所有节点都在运行时由代码创建，`main.tscn` 里只有根节点。
- 画面分层（从下到上）：竞技场 → 道具 → 敌人 → 玩家 → 子弹 → 特效 → HUD（CanvasLayer）。
- 一帧内新生成的敌人和子弹（地雷、小怪、碎片、Boss 弹幕）先放进待加入列表，帧末统一并入，避免在遍历列表时修改它。
- 网页导出为单线程版本，不需要跨域隔离响应头，可以直接托管在 GitHub Pages。

## 15. 已知限制

- 只支持键盘加鼠标，手机和平板无法操作。
- 只有英文和简体中文；新增中文文字后需要重新生成字体子集，否则新字会显示成方块。
- 没有背景音乐，没有音量设置。
- 升级数值和敌人强度还没经过大量真人试玩，平衡性需要根据实际手感再调。
- 网页版首次加载约 40 MB（主要是 Godot 引擎本体）。

## 16. 后续规划（尚未实现）

按优先级排序：

1. **背景音乐**：合成器风格循环曲，Boss 战时切换曲目；加音量设置。
2. **击败 Boss 额外奖励一张升级卡**：可选，用来补偿升级间隔拉长后后期的成长。
3. **触屏支持**：双虚拟摇杆（左摇杆移动、右摇杆瞄准并射击）和冲刺按钮。
4. **平衡调整**：根据试玩调整升级数值、精英比例和后期波次强度；考虑加入升级之间的联动（例如「弹射 + 碎裂」的专属进化）。
5. **更多敌人**：自爆兵（接近后延时爆炸）、正面护盾兵（需要绕后或用弹射打）。
6. **竞技场变化**：每隔几波更换柱子布局，或加入可破坏的掩体。
7. **局外成长**：解锁新武器（如榴弹、回旋镖）和起始升级，增加长期目标。
8. **最终命名**：候选有 Gridlock 锁格、Pulse Core 脉冲核心、Neon Siege 霓虹围城等，尚未决定。
