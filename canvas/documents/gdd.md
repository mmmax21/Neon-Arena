# Neon Arena 游戏设计文档

> 状态：可玩原型 · 引擎：Godot 4.3+（GL Compatibility）· 平台：网页（桌面浏览器 + 手机 / 平板横屏）
> 在线试玩：https://mmmax21.github.io/Neon-Arena/（版本选择页）· 源码：https://github.com/mmmax21/Neon-Arena
> 版本：**v2.3**（本文档描述的版本：5 个 Boss 随机顺序、Boss 出场倒计时、全屏按钮；试玩 /v2/）· v2.2（`v2.2` 标签：在线排行榜、联机合作、大场地）· v2.1（`v2.1` 标签）· v2.0（`v2.0` 标签）· v1.0 初版（`v1` 分支 / `v1.0` 标签，试玩 /v1/）
>
> 本文档记录**当前已实现**的设计与数值。标注「规划」的内容尚未实现。

## 1. 概述

**一句话**：在一个霓虹网格竞技场里，驾驶一艘箭头形战机，选一把主武器，每清一波就从三张升级卡里挑一张，用冲刺穿越弹幕，抵挡一波比一波凶的几何体敌人，并冲击最高分。

- **类型**：俯视角竞技场射击（Twin-stick 式操作，键鼠），带 Roguelite 式的单局构筑
- **单局时长**：3–10 分钟，失败即重开
- **目标玩家**：喜欢短局、高节奏、追分的动作游戏玩家
- **胜负**：没有通关，生命值归零时结算分数

## 2. 设计支柱

1. **一眼就懂**：纯几何图形 + 高对比霓虹配色。每种敌人靠形状和颜色区分，不需要教程。
2. **爽快反馈**：每一发子弹都有枪口火花、命中火花、击退、震屏和音效。击杀会出现爆炸粒子、扩散光环和浮动分数。
3. **冲刺是核心技巧**：冲刺带短暂无敌，玩家能主动穿过弹幕、激光和敌群。高手和新手的差距主要体现在这里；冲刺也有专属升级。
4. **每局都不一样**：主武器 × 升级卡组合出不同的打法（例如「弹射 + 追踪」的脉冲枪、「冲击波 + 火焰冲刺」的近战流）。
5. **零外部资源**：所有画面都用代码绘制，所有音效都在运行时合成，加载快、修改方便。

## 3. 核心循环

```
选主武器 → 波次开始 → 敌人在预警圈处陆续刷出 → 移动、射击、冲刺求生
   → 击杀得分、累积连击、捡道具 → 清空本波 → 清波奖励 →（每 3 波）三选一升级 → 下一波（更难）
                                         ↘ 生命归零 → 结算 → R 同武器重开 / 点击重新选武器
```

## 4. 操作

| 动作 | 输入 |
|---|---|
| 移动 | WASD / 方向键（8 方向，带加速惯性） |
| 瞄准 | 鼠标（系统光标隐藏，显示自定义准星） |
| 射击 | 按住鼠标左键连射 |
| 冲刺 | 空格 / Shift / 鼠标右键（按下时触发） |
| 选卡（武器 / 升级） | 点击卡片，或按 1 / 2 / 3 |
| 切换语言 | 标题页右上角点「English / 中文」，或任何时候按 L |
| 静音 | 点右上角的喇叭按钮（所有界面都在同一位置），或任何时候按 M |
| 全屏 | 点喇叭按钮下方的四角框按钮，或任何时候按 F；再按一次退出（浏览器里按 Esc 也会退出全屏） |
| 暂停 | P / Esc（窗口失去焦点时自动暂停；选武器界面按 Esc 返回标题） |
| 开始 / 重开 | 标题页点击或回车进入选武器；结算页按 R 用同一把武器重开，点击则重新选武器 |

以上是电脑（键盘 + 鼠标）操作。手机和平板见 4.1。

### 4.1 触屏操作

参考元气骑士（Soul Knight）的「左摇杆移动 + 自动瞄准」，以及 Brotato、Vampire Survivors 手机版的单手自动射击，同时保留 Geometry Wars 3 手机版那种右手手动瞄准的双摇杆玩法，供熟练玩家使用。

**何时启用**：在 Android / iOS 浏览器里一打开就是触屏模式；在其他设备上，第一次触摸屏幕时切换过去。触屏模式下再用真实鼠标移动（距上次触摸超过 1 秒），会切回电脑操作。两种模式下画面里的提示文字、按钮都会对应切换。

| 动作 | 触屏操作 |
|---|---|
| 移动 | 左半屏任意位置按下，摇杆就在那里出现，拖动即移动（半径 78，死区 15%，有模拟量）；手指拖得超出半径时，摇杆底座会跟着手指走 |
| 瞄准 / 射击 | 按操作模式决定，见下表 |
| 冲刺 | 右下角大按钮，按钮外圈显示冷却进度。冷却中按下会保留 0.2 秒，冷却一结束就冲刺；方向优先取移动方向 |
| 锁定目标 | 冲刺按钮左边的小按钮：锁定当前自动瞄准的目标，直到它死掉或再点一次；锁定时目标框变红 |
| 暂停 | 右上角静音按钮下面的暂停按钮；切到别的应用或把手机竖过来也会自动暂停 |
| 选卡、菜单 | 点击。在菜单里手指抬起时才算点击（按住不超过 0.45 秒、移动不超过 36 px），所以长按不会误触 |
| 查看图标说明 | 暂停或结算时长按左上角图标 |

**三种操作模式**（标题页右上角和暂停页的「操作：…」按钮切换，会保存设置）：

| 模式 | 说明 |
|---|---|
| 混合（默认） | 自动瞄准、自动开火；右半屏拖动立刻切成手动瞄准，按住就连射；松手后保持手动朝向 1 秒，再切回自动 |
| 全自动 | 只有自动瞄准，右半屏触摸不起作用，单手就能玩 |
| 双摇杆 | 没有自动瞄准；右半屏拖动瞄准，按住即射击，松手停火 |

**自动瞄准规则**：
- 每 0.15 秒重新选一次目标，评分 = 距离 × 优先级系数，分数最低的当目标。系数：哨塔 0.6、射手 0.75、布雷者 0.85、追击者 0.9、闪避者 / 分裂者 / 小怪 / 长蛇头 1.0、坦克 1.15、Boss 1.3、地雷 1.8。被柱子挡住 ×3，超出射程 ×2。
- 新目标的分数要比当前目标低 25% 以上才会换，避免准星来回跳。
- 只在目标进入射程（脉冲 760、霰弹 340、激光 1000）、中间没有柱子挡住、枪口已基本对准时才开火。
- 子弹类武器会按敌人的速度预判提前量（最多 0.6 秒）。激光会在射程内的敌人里，挑一条能同时穿过最多敌人的直线来瞄。
- 没有目标时，飞船朝移动方向。
- 当前目标头上显示黄色四角框，锁定时变红。

**其他适配**：
- 竖屏时显示「请把手机横过来」，并暂停游戏。
- 网页里第一次触摸时，会尝试进入全屏并锁定横屏（Android Chrome 支持；iPhone Safari 不支持网页全屏，会跳过）。页面禁止了下拉刷新和长按选中文字。
- 退出全屏后可以在标题页、暂停页点右上角的全屏按钮重新进入；游戏进行中触屏不显示这个按钮，避免误触。
- iPhone：浏览器不支持全屏，按钮不显示，标题页底部提示「点分享 → 添加到主屏幕，再从桌面图标打开」。网页带了 `apple-mobile-web-app-capable` 标记，从主屏幕打开时没有地址栏和工具栏。
- 触屏模式下隐藏准星，卡片上不显示 [1][2][3] 键位，提示文字改成「点击」。
- 手机上粒子上限从 900 降到 500。
- 引擎的「触摸模拟鼠标」已关闭，触摸全部交给 `scripts/touch.gd` 处理。

## 5. 玩家

| 属性 | 数值 |
|---|---|
| 生命 | 6 格 |
| 移动速度 | 290 px/s（插值加速，系数 12） |
| 碰撞半径 | 15 px（被子弹判定时用 70%，即约 10.5 px，判定偏宽松） |
| 受伤无敌 | 1.1 秒（期间闪烁），受伤会清空连击 |

**冲刺**：持续 0.16 秒，速度 860 px/s，冷却 1.0 秒（可被升级缩短），冲刺期间及之后 0.08 秒无敌。方向优先取移动方向，不移动时取瞄准方向。会留下残影；飞船外圈的环形进度条显示冷却。

**射击输入**：按住左键连射；一次很短的点击（按下和松开落在同一帧）也会被记下，在冷却好后补射一发。

## 5.1 主武器

开局在三张武器卡里选一把，整局不换。武器的颜色也是它子弹 / 光束的颜色。

| 武器 | 定位 | 射击间隔 | 每次射击 | 伤害 | 特点 |
|---|---|---|---|---|---|
| 脉冲 PULSE | 均衡 | 0.13 秒 | 1 发，速度 780，存在 1.4 秒，散布 ±0.04 | 1 | 原来的默认武器，后坐力最小 |
| 霰弹 SCATTER | 近距离 | 0.5 秒 | 5 颗弹丸，扇形 0.5 弧度，速度 620–760，只存在 0.5 秒 | 每颗 1 | 贴脸爆发高，射程约 350 px，后坐力大 |
| 激光 LASER | 穿透 | 0.38 秒 | 一道瞬发光束，打到柱子 / 墙 / 长蛇身体为止 | 2.2 | 穿透光束上的所有敌人，闪避者躲不开它 |

**多重射击**对不同武器的效果：
- **脉冲**：正中的瞄准弹始终是全额伤害，额外子弹只有 50% 伤害。1 级：每次在左右交替多 1 发（±0.11 弧度）；2 级：左右各 1 发；3 级：左右各 1 发，外侧再交替多 1 发（±0.22 弧度）。每级约 +50% 火力。
- **霰弹**：每级多 2 颗弹丸，扇面加宽 0.08。
- **激光**：每级多 1 道光束，间隔 0.09 弧度。

**武器平衡目标**（参考《Game Balance》的锚点思路）：以初始脉冲的有效火力（约每秒 7.7 伤害）为 1.0。每把武器在一整波里平均约 0.9–1.1，擅长的场合约 1.3，不擅长的约 0.7。霰弹的弹丸存在时间从 0.42 秒提到 0.5 秒，就是为了把中距离从约 0.4 提到约 0.7。火力类卡每级目标约 +20% 有效火力（多重射击约 +40–50%），叠满约 12 倍，原来约 31 倍。

## 5.2 升级卡（三选一）

**发放间隔：每清完 3 波发一次**（第 3、6、9……波之后）。顶部波次下方有「升级 ◆◆◇」进度条，显示离下一张卡还差几波。

选 3 波而不是 5 波或 8 波的理由：
- 一局一般打 8–15 波，每 3 波一张卡能拿到 3–5 张，足够凑出一套有特色的组合；每 5 波只有 1–3 张，每 8 波只有 1–2 张，14 种升级大部分根本见不到，三选一也就失去意义。
- 每 3 波的节奏和 Boss（每 5 波）错开：Boss 战前后都会有一次变强的机会，不会出现连续很多波没有成长的空档。
- 卡变少后，每次选择更有分量，也不会像每波都发那样频繁打断战斗。

间隔由 `main.gd` 里的 `UPGRADE_EVERY` 常量控制，调平衡时只改这一个数。

清完到达间隔的那一波后，结算奖励后约 1.1 秒弹出升级界面，游戏暂停，从 3 张卡里选 1 张。选完后休整 1.4 秒开始下一波；其他波次之间照常休整 2.6 秒。界面打开后 0.5 秒内不接受输入，防止连射时误点。

**分类**：升级分成 4 类，每类一种颜色，卡片顶部、HUD 图标边框和悬停提示都用这个颜色：

| 类别 | 颜色 | 包含 |
|---|---|---|
| 火力 FIREPOWER | 橙红 | 速射、多重射击、威力、暴击 |
| 弹道 BALLISTICS | 黄 | 穿透、弹射、追踪、碎裂 |
| 冲刺 DASH | 青 | 火焰冲刺、冲击波、快速冲刺 |
| 生存 SURVIVAL | 绿 | 活力、屏障、磁铁（以及修复卡） |

**抽卡规则**：从「未满级、且当前武器能用」的升级里抽 3 张。生命不满时可能出现「修复」：生命 ≤ 一半时必出，否则 25% 概率出现（替换第 3 张）。可选升级不足 3 张时，用「奖金」补位。

**防坏运气**（避免连续几次都抽不到想要的方向）：
- **类别分散**：3 张卡尽量来自 3 个不同类别；某类别已满级时才允许重复。这样每次最多只出现 1 张火力卡。
- **保底权重**：一个升级每次「可以出现但没出现」，下次出现的权重 +0.5，最多叠 4 次（权重 3 倍）；出现过一次就清零。每局重新计算。
- 参数在 `main.gd`：`PITY_STEP`、`PITY_MAX`。

### 5.3 进化卡

参考《吸血鬼幸存者》的武器进化和《Hades》的双神祝福：冲刺类和生存类卡凑齐指定组合后，会解锁一张更强的**进化卡**（洋红色，类别名「进化」，底部标「进化」）。这样选非火力卡是在为进化卡做投资，不再是浪费一次选择。

| 进化 | 需要 | 效果 |
|---|---|---|
| 相位冲刺 PHASE DASH | 快速冲刺 3 级 + 冲击波 | 冲刺穿过的敌人受到 4 × 威力 伤害（每次冲刺每个敌人一次，可暴击）；冲刺中击杀敌人会立刻重置冲刺冷却 |
| 反应护甲 REACTIVE ARMOR | 屏障 + 活力 2 级 | 屏障充能从 15 秒缩短到 9 秒；屏障破碎时爆炸：半径 150，6 × 威力 伤害，击退敌人，并清除 220 px 内的敌方子弹 |
| 地狱火径 INFERNO | 火焰冲刺 + 快速冲刺 1 级 | 火焰持续 2.8 秒（原 1.4），伤害翻倍，火里的敌人移速减半（Boss 不受减速影响） |
| 磁暴 MAGSTORM | 磁铁 2 级 + 活力 1 级 | 每拾取一个道具，以自身为中心释放脉冲：半径 160，4 × 威力 伤害，清除范围内敌方子弹；掉落率再 +20% |

- **出现规则**：条件满足后，下一次三选一的**第 1 张必定是进化卡**（一次只出一张），玩家可以不选，下次还会出现。进化卡不参与保底权重。
- **提示**：暂停或结算时，把鼠标移到（手机上长按）左上角已拥有的升级图标上，提示里会写「可进化：XX（A + B 2 级）」，告诉玩家它是哪张进化卡的素材。

每张卡顶部是类别名，中间是该升级的图标，底部显示「新」「等级 1 → 2」「唯一」或「进化」（英文为 NEW / LV 1 → 2 / UNIQUE / EVOLVED）。

**图标**：3 把武器和 14 种升级（加上修复、奖金）（以及 4 张进化卡）各有一个霓虹线条图标，全部由 `scripts/icons.gd` 用代码绘制，不用图片。例如：速射是双箭头 »，多重射击是三支扇形箭，暴击是准星，穿透是箭头穿过圆圈，弹射是撞墙折返的折线，追踪是弧形箭头，碎裂是 Y 形分叉，火焰冲刺是火苗，冲击波是向两侧扩散的波纹，屏障是六边形，磁铁是 U 形磁铁；进化卡：相位冲刺是切开菱形的斜线，反应护甲是带放射线的六边形，地狱火径是双层火苗，磁暴是磁铁加闪电。

## 6. 敌人

**坦克冲撞**（《Game Balance》第 10 章：把"子弹海绵"改成考验时机的敌人）：
1. 与玩家距离小于 420 px 且中间没有柱子挡住时，冷却到了就停下蓄力 0.8 秒，朝玩家拉出一条红色预警线；前 0.55 秒跟着玩家转，最后 0.25 秒锁定方向。
2. 以每秒 540 px 冲撞最多 1 秒。撞到玩家会造成伤害并结束冲撞。
3. **撞到柱子或墙会晕 1.5 秒**：身上出现闪烁的黄色破绽圈和绕头转的火花，这期间**受到双倍伤害**。
4. 结束后休息 0.6 秒，冷却 3.5–5 秒后才会再冲。正确打法是引它撞柱子，然后集火。

### 6.1 精英敌人

从第 7 波开始，追击者、射手、坦克、分裂者、闪避者、哨塔、布雷者有 min(5% × (w − 6), 35%) 的概率以精英身份出现：生命 ×1.5、分值 ×2、掉落率 ×4，刷怪预警圈变成金色，身上有一圈旋转光环。每个精英带一个词缀：

| 词缀 | 光环颜色 | 效果 |
|---|---|---|
| 护盾 Shield | 浅蓝 | 额外 min(3 + ⌊w/3⌋, 8) 点护盾，**只挡正面**：从它面朝方向左右各约 69° 内打来的攻击（包括爆炸）先扣护盾；从侧面和背后打来的直接扣血；火焰这类没有方向的伤害不受护盾影响。护盾显示为面前一段蓝色弧，越厚剩得越多；护盾期间几乎不被击退 |
| 疾速 Haste | 黄 | 移速 ×1.45；闪避者的闪避冷却缩短到 0.5 秒 |
| 爆裂 Volatile | 橙 | 死亡时向四周射出 10 发子弹 |

### 6.2 Boss：CORE WARDEN

- 在第 5、15、25……波出现（和 VOID WEAVER 轮流），排在该波刷怪队列的最前面。刷出时预警 1.4 秒，并伴随震屏。
- 移动：距离玩家超过 220 px 时逼近，否则缓慢后退。
- **攻击循环**依次为：环形弹幕 → 扇形散射 → 环形弹幕，然后重复。
  - 环形弹幕：16 发（第 2 阶段起 22 发），速度 210，整体随 Boss 的旋转角偏移，每次缺口位置不同。
  - 扇形散射：朝玩家打 7 发，间隔 0.14 弧度，速度 330。
  - 攻击间隔：环形 1.5 秒 / 散射 1.1 秒；第 2 阶段 1.1 / 0.8 秒；第 3 阶段环形 0.9 秒。
- **第 2 阶段**：旋转加快、弹幕更密，并放出 **4 颗环绕卫星**（距 Boss 92 px），轮流朝玩家打瞄准弹（每 0.6 秒一发，第 3 阶段 0.45 秒）。
- **第 3 阶段「引力核心」**：Boss 每秒把玩家往自己身边拉 75 px，冲刺时不受影响，距离小于约 120 px 时也不再拉。站着不动会被拉进贴身距离，必须持续走位。身边有收缩的引力波纹。
- 屏幕底部显示 Boss 名字和血条。击败后必定掉落一个修复和一个超载道具。

### 6.3 Boss：VOID WEAVER

- 距离玩家超过 300 px 时逼近，否则后退。
- **攻击循环**依次为：旋转激光 → 螺旋弹幕 → 召唤，每次攻击之间停顿约 0.8–1.2 秒。
  - 旋转激光：先显示 3 道（第 2 阶段 4 道）闪烁的预警线 1.1 秒，然后变成实体激光持续 2.6 秒，以每秒 0.7（第 2 阶段 1.0）弧度旋转，每次换方向。Boss 此时站定。激光被柱子挡住，可以躲在柱子后面，或者冲刺穿过。
  - 螺旋弹幕：2.2 秒内每 0.08 秒（第 2 阶段起 0.06 秒）射出 2 条（第 2 阶段起 3 条）旋转的子弹臂，速度 220。
  - 召唤：在身边召唤 4 个（第 2 阶段起 6 个）小怪；场上小怪已有 10 个以上时跳过。
- **第 2 阶段**：数值加强，攻击循环多一招**闪现**：在玩家附近 200–340 px 处先出现收缩的紫色落点圈（0.8 秒），然后瞬移过去并向四周射出 18 发子弹。
- **第 3 阶段「双向激光」**：旋转激光变成两组各 3 道、**反向旋转**（每秒 0.5 弧度），扫过的区域会交叉，需要找缝隙或冲刺穿过。
- 击败后同样掉落一个修复和一个超载道具。

### 6.4 Boss 阶段（所有 Boss 通用）

参考 Furi 的分段血条和 Mike Stout「战斗中段是情绪转折点」的说法，Boss 血量分成三段：

- 血量降到 **2/3** 和 **1/3** 时进入下一阶段。单次伤害再高也会停在阈值上，所以三个阶段一定都会出现。
- **转场 2 秒**：Boss 无敌（套上闪烁的白色护罩，血条变白），清掉全场敌方子弹，把 260 px 内的玩家震开，屏幕中央显示「第 2 阶段」或「第 3 阶段」。转场结束后约 0.4–0.6 秒才开始攻击。
- 血条在 1/3 和 2/3 处有刻度线。
- **实测**（自动瞄准、第 15 波、玩家无敌）：不升级的脉冲打 CORE WARDEN 约 38 秒、VOID WEAVER 约 42 秒；带 5 张火力卡约 19 秒。分段之前速杀只要 10 秒左右。

### 6.5 Boss：RAZOR COMET（裂空彗星，v2.3）

战场：传送带堡垒（中间一排柱子是引它撞上去的目标）。

- **游走**：在玩家 240–360 px 外绕圈，每 1.3 秒（第 3 阶段 1.0 秒）射一组扇形弹：5 发（第 3 阶段 7 发），速度 300，带一半提前量。第 2 阶段起每隔一组再加一圈 14 发环形弹（速度 170）。
- **冲刺**：游走 2.2 秒（第 3 阶段 1.6 秒）后进入冲刺：
  - 先显示和彗星一样宽的红色**冲刺通道**预警 0.9 秒，前 0.6 秒跟踪玩家，最后 0.3 秒锁定。
  - 以 880 px/s 冲出，最远 1000 px。冲刺路径每 44 px 留下一个光点，冲刺结束 0.35 秒后所有光点同时向两侧射出子弹（第 3 阶段每 3 个光点再多射两发斜向弹）。
  - 连冲次数 = 当前阶段数（1 / 2 / 3 次），连冲之间重新瞄准 0.55 秒。
- **撞柱眩晕**：冲刺撞上柱子或水晶（撞外墙不算）会眩晕 1.6 秒，连冲中断，期间受到双倍伤害（和坦克一样）。玩法就是站在柱子前面引它冲过来，然后闪开。
- 外形：第 2 阶段长出两片尾鳍，第 3 阶段外圈有旋转的弧线。

### 6.6 Boss：STORM BEACON（风暴信标，v2.3）

战场：双传送门（传送门可以用来躲光栅；水晶会被空袭炸掉）。

- 在玩家 300–440 px 外缓慢横移。攻击循环（第 2 阶段起多一招召唤）：
  - **空袭**：在玩家位置（带移动提前量）和附近随机处标出 3 个（第 2 阶段 5 个）半径 74 的圆圈，1.15 秒后落下：圈内玩家受 1 点伤害，并炸伤圈内水晶。落下前 0.2 秒有一道白光柱。第 2 阶段起每次爆炸再向四周散出 6 发子弹。
  - **光栅**：横贯整个场地的激光线，先闪烁预警 1.0 秒，再变成实体激光 0.45 秒（宽 26）。第 1 阶段只有一个方向（竖或横，间距 220），第 2 阶段起横竖交织成网格（间距 250），总有一条线落在玩家附近。第 3 阶段打完一次后，网格平移半格再打一次（预警 0.75 秒）。
  - **能量球**：3 发（第 2 阶段 5 发）大号慢速弹（半径 14，速度 150）。
  - **召唤**（第 2 阶段起）：场上哨塔少于 2 个时，在身边召唤 2 个激光哨塔。
- **第 3 阶段「风暴」**：除了攻击循环，每 1.8 秒在玩家脚下再追加一次空袭，必须一直移动。

### 6.7 Boss：NEON HYDRA（霓虹巨蛇，v2.3）

战场：空旷场（足够绕圈）。

- 16 节身体，每节半径 19、间距 30，全长约 500 px。和长蛇一样**只有头能受伤**，身体挡子弹和激光，碰到身体扣 1 点、碰到头扣 2 点。血量因此比其他 Boss 低。
- **移动**：朝向有转向速度上限（每秒 2.4 弧度），速度 165（每阶段 +15%），可以靠急转弯甩开；看不到玩家时沿寻路网格绕过障碍。
- 攻击循环：
  - **吐息**：减速，连吐 3 组扇形弹（5 发，第 2 阶段起 7 发，速度 290，带提前量）。
  - **侧舷齐射**：身体闪白 0.7 秒预警，然后每一节向身体两侧各射一发（速度 170）。第 2 阶段起 0.45 秒后从新位置再射一轮。
  - **盘绕**（第 3 阶段）：4 秒内绕着玩家转圈，半径从 270 收到 160，每 0.6 秒从每 4 节身体朝玩家射一发。
- 第 2 阶段起追击时尾巴每 0.55 秒朝玩家射一发；每次换阶段时尾部分裂出一条普通长蛇（场上长蛇少于 3 条时）。
- **测试观察**（自动测试，非真人）：玩家持续高速绕圈时巨蛇几乎打不中，玩家慢慢移动时它是 5 个 Boss 里伤害最高的。实际难度要看真人手感。

### 6.8 Boss 出场倒计时（v2.3）

为了让 Boss 出场有压迫感，Boss 波开始时不再直接刷出 Boss，而是先有 3.6 秒的出场演出：

- **0–0.6 秒**：警报音，屏幕中央闪烁大字「警告」。
- **之后每秒一个数字 3、2、1**：数字落下时先放大再回弹，伴随低沉的「咚」声，震屏逐次加强（3 → 6 → 9），落点处扩散一圈红环。
- 全程：屏幕四周红色暗角向内收紧并随心跳闪烁；上下两条反向滚动的警示带写着「警告 · 强敌接近」；屏幕下方显示「第 N 波 — Boss 名」和一句打法提示（例如裂空彗星：「沿红线冲刺 · 引它撞柱会眩晕」）。
- **落点**：Boss 落在玩家 330–470 px 外的空地上（在屏幕内，能看到），落点处有旋转收缩的红色法阵，越接近 0 转得越快；最后 0.5 秒有一道光柱。落点在画面外时边缘有红色大箭头。
- **落地**：Boss 出现时大震屏、白色冲击环、爆裂粒子和重低音，屏幕中央显示 Boss 名。150 px 内的玩家会被推开，不会被砸中。同波的普通敌人在 Boss 落地 1.6 秒后才开始刷出。
- 倒计时期间可以自由移动和射击，暂停时倒计时也暂停。联机时队友端同步显示倒计时和法阵。

## 7. 波次系统

| 参数 | 规则 |
|---|---|
| 每波敌人数 | min(4 + 2w, 24)：第 10 波起封顶 24 只（Boss 波另加 1 个 Boss）。之后难度靠血量、精英和场地组合提升，每波时长基本稳定，升级卡的间隔不会越拖越长 |
| 敌人种类 | 按权重从已解锁的敌人里随机抽：追击者 10、射手 4、分裂者 3、坦克 2、闪避者 3、哨塔 2、布雷者 2、长蛇 1。第 10 波起按当前场地调整权重，见 7.2 |
| 数量上限 | 每波坦克 ≤ 2 + ⌊w/3⌋，哨塔 ≤ 1 + ⌊w/5⌋，布雷者 ≤ 1 + ⌊w/6⌋，长蛇 ≤ 1 + ⌊w/8⌋；超出的换成追击者 |
| 精英 | 见 6.1 |
| Boss | w 是 5 的倍数时出现。每局开始时把 5 个 Boss 随机排序，第 5、10、15、20、25 波依次遇到，一轮内不重复；之后再洗一轮，新一轮的第一个不会和上一轮最后一个相同。每个 Boss 有专属战场（CORE WARDEN 空旷场、VOID WEAVER 经典、RAZOR COMET 传送带堡垒、STORM BEACON 双传送门、NEON HYDRA 空旷场），Boss 波前的间歇自动切换 |
| 刷怪间隔 | max(0.22, 0.85 − 0.05w) 秒，逐只刷出 |
| 刷怪预警 | 先出现闪烁的红色十字圈，0.9 秒后敌人出现。Boss 改为 3.6 秒的出场倒计时，见 6.8 |
| 刷怪位置 | 场地内随机，距玩家至少 300 px、离柱子边缘至少 60 px、不在传送门旁 |
| 清波条件 | 刷怪队列、预警圈、存活敌人（地雷除外）全部清空 |
| 清波时 | 加 100 × w 分；场上的敌方子弹和地雷全部消散 |
| 节奏 | 开局休整 1.2 秒；普通清波后休整 2.6 秒；每第 3 波清波 → 1.1 秒 → 升级界面（暂停）→ 选完后场地变换，2.6 秒 → 下一波 |

波次无上限。难度主要靠这几点逐步提升：敌人数量增加（到 24 封顶）、刷怪更快、敌人更耐打更快、新敌人种类和精英逐渐加入、后期的场地组合。玩家这边靠每 3 波一张升级卡变强。

### 7.1 节奏起伏：喘息波与高峰波

参考《Game Balance》第 10、11 章「紧张—放松」的思路，难度不再是一条平滑上升的直线：

| 波次类型 | 何时出现 | 规则 |
|---|---|---|
| 喘息波 | Boss 波的下一波（第 6、11、16……波） | 敌人数 ×0.6，不出精英 |

## 9. 计分

- **击杀得分** = 敌人分值 × 连击倍率。
- **连击**：每次击杀 +1，2.5 秒内没有新的击杀就清零，受伤也清零。
- **连击倍率** = 1 + min(连击 − 1, 20) × 0.1，最高 3 倍。
- **清波奖励**：100 × 波次。
- **最高分按操作方式分开记录**，共 4 个榜：键鼠、双摇杆、混合、全自动。保存在本地 `user://best_v2_modes.cfg`（网页版存在浏览器存储里）。
  - 一局算哪个榜：取这局中用过的**辅助最多**的方式，顺序为 键鼠 < 双摇杆 < 混合 < 全自动。比如中途从键鼠切到全自动，这局就计入全自动榜。
  - 标题页显示当前操作方式的最高分，游戏中和结算页显示这局所属榜的最高分，都带榜名，例如「最高分（键鼠）」「混合 最高」。
  - 旧版只有一个最高分（`user://best_v2.save`），第一次运行时自动迁移到键鼠榜。

### 9.1 在线排行榜

后端用 Cloudflare Workers + D1（免费额度），代码在 `server/`，部署步骤见 `server/README.md`。游戏端是 `scripts/net.gd`。`API_URL` 留空时游戏里不出现排行榜，其他一切照常。

- **分榜**：先按**设备平台**分（电脑 / 手机 / 平板），每个平台下再按**操作方式**分 4 个子榜（键鼠 / 双摇杆 / 混合 / 全自动），每个子榜都有**总榜 / 本周 / 今日**。「今日」「本周」按北京时间（UTC+8）计算，一周从周一开始。
  - 平台识别：浏览器报告粗指针（触屏为主）或手机 UA 时算触屏设备，屏幕短边 < 600 CSS 像素为手机，否则为平板；其余都算电脑。
  - 一局归哪个子榜：沿用本地分榜规则，取这局用过的辅助最多的方式。
- **赛季**：从 v2.2 开始第 1 赛季。开新赛季只需把服务器的 `SEASON` 加 1，旧数据保留但不再显示。本地最高分不进线上榜。
- **身份**：不用注册。第一次运行生成匿名玩家 ID 和设备密钥，存在 `user://player.cfg`（网页版存在浏览器存储里）。换浏览器或清除网站数据就是新身份。
- **昵称**：默认 `Pilot-xxxx`；在排行榜页点「昵称」用浏览器输入框修改，最多 12 个字，不做过滤。
- **一局的流程**：开局时向服务器领一次性编号 → 结算时带着编号提交（平台、子榜、分数、波次、击杀、时长、武器、版本）→ 结算页显示「电脑 · 键鼠 — 本周第 3 名 · 总榜第 12 名（共 230 人） 离上一名还差 680 分」。开局没领到编号（离线）时，结算页提示「离线：这局成绩没有上传」。
- **排行榜页**：标题页左下角、结算页下方都有「排行榜」按钮。顶部三排标签切换平台、子榜、时间范围，下方两列显示前 20 名（名次、武器图标、昵称、波次、分数），自己的那行高亮，底部显示自己的名次和离上一名的差距。停留期间每 15 秒自动刷新。Esc / Enter / 「返回」回到进来之前的页面。
- **防作弊**（只挡随手改分，网页游戏无法完全防作弊）：
  - 编号只能用一次，只能由领取它的玩家提交；玩家密钥在服务器上只存哈希。
  - 服务器用自己的时钟核对时长：声称的时长比服务器看到的多 15 秒以上就判为不合理。
  - 合理性上限：分数 ≤ 击杀 × 3000 + 清波奖励 + 奖金卡 + Boss 分；时长 ≥ (波次 − 1) × 4 秒；击杀 ≤ 时长 × 15 + 20。不合理的成绩照样记录，但标记为无效，不进榜；结算页会提示「没通过服务器校验」。
  - 频率限制：每个玩家每小时最多开 40 局，每个 IP 每小时最多 200 局。
- **字体**：玩家昵称可能是任意中文，所以网页字体收录了 GB2312 全部 6763 个常用汉字和全角符号，约 1.6 MB。生僻字和 emoji 可能显示不出来。
## 10. 竞技场

- 可活动区域 1708 × 924（v2.2 起为原来单屏 1220 × 660 的 1.4 倍），带 40 px 网格底纹和发光边框。画面仍是 1280 × 720。
- **跟随镜头**（参考 Nuclear Throne）：镜头跟着玩家，并往瞄准方向前移 90 px；平滑跟随，视野不超出场地边框 40 px。屏幕比场地宽或高时居中显示。
- **屏幕外提示**：画面外的敌人在屏幕边缘显示同色箭头，越近箭头越大，Boss 箭头更大；画面外的刷怪预警显示闪烁的红色箭头。保留"敌人出现前一定有预告"的原则。
- **同屏敌人上限**（参考 Brotato）：场上敌人加刷怪预警最多 22 个（触屏 18 个），地雷、Boss 召唤的小怪和 Boss 本身不计。超出部分排队，前面的敌人死了再刷。刷怪点离玩家 300～950 px。
- **敌人互相推开**：敌人之间做软碰撞，不再叠成一团；Boss 和哨塔不会被推动。
- 手工布局以原 1280 × 720 坐标设计，锚点按 1.4 倍映射到新场地，L 形墙等成组柱子保持原来的贴合间距，墙不会出现缝。
- 柱子和水晶会挡住玩家、敌人和所有子弹（子弹撞到会溅出火花）。
- 场地逻辑和绘制都在 `scripts/arena.gd`；碰撞仍用 `main.obstacles` 里的圆形判定，由 arena.gd 根据当前实体的柱子 / 水晶重建。

### 10.1 变形竞技场

参考 Assault Android Cactus（关卡中途地形重组）、Nex Machina（分段变化的激光栅栏和机关）、Geometry Wars 3（场地形状本身就是玩法）：场地始终一屏，但会周期性换布局，迫使玩家重新找站位。

- **换图时机**：前 3 波固定为「经典」。之后每次选完升级卡（每 3 波一次）立刻换一张新布局，和升级节奏同步。
- **抽取规则**：6 种布局放进打乱的「牌袋」依次抽出，抽完重新洗牌；不会连续两次是同一张。
- **过渡**：中央提示「场地变换 — 布局名」。旧柱子闪烁 0.6 秒后消失（消失前仍有碰撞）；新柱子位置先显示旋转的黄色虚线预警圈，1.2 秒后升起成为实体（0.25 秒的放大动画）。机关（激光栅栏、传送带、传送门）在新柱子升起后才启动，启动前半透明显示。选卡后的休整时间从 1.4 秒延长到 2.6 秒，留出换图时间。
- **防卡住**：玩家和敌人每帧都会被推出柱子，新柱子升起时也不会把人卡在里面；道具在布局变化时同样被推出。
- 顶部波次下方显示当前布局名（「场地 十字走廊」）。

| 布局 | 柱子 | 机关 |
|---|---|---|
| 经典 | 四角 4 根大柱（半径 42）+ 上下中线 2 根小柱（半径 28），中心留空 | 无 |
| 十字走廊 | 四角各一组 3 根柱子组成的 L 形，中间留出十字形走廊 | 走廊里 8 块**水晶掩体**（半径 22，8 点耐久）：子弹、激光、爆炸、冲击波都能打碎，敌人子弹每发扣 1 点；耐久降到 60% 以下出现裂纹，打碎加 10 分 |
| 环形激光 | 中心 8 根小柱围成半径 230 的圆环，四角另有 4 根大柱 | 相邻柱子之间的**激光栅栏**分两组交替：每组 3 秒开、3 秒关，开启前闪烁预警 0.6 秒。玩家碰到扣 1 格生命，敌人每 0.4 秒掉 1 点血 |
| 传送带堡垒 | 中心 1 根巨柱（半径 56）+ 左右 2 根 | 上下两条反向**传送带**（上向右、下向左），以 150 px/s 推动玩家、敌人（Boss 除外）、道具和子弹 |
| 双传送门 | 4 根大柱 + 2 块水晶 | 左右两扇**传送门**互通：玩家、敌人（Boss、长蛇、地雷除外）和子弹都能穿过，保持原方向飞出，0.6 秒冷却防止来回传送；刷怪点避开传送门附近 |
| 空旷场 | 只有四角 4 根小柱（半径 18） | 无，纯靠走位 |

## 10.2 联机合作（v2.2，2 人原型）

- **入口**：标题页「联机合作」按钮（服务器地址配置后才出现）→ 房间页：创建房间得到 4 位房间号，另一人点「加入房间」输入房间号。两人各自选武器，房主点「开始」。
- **架构**：房主权威。房主的游戏模拟一切（包括队友的飞船），每秒 15 次发快照（敌人、子弹、道具、刷怪预警、火焰、分数、状态），场地布局变化时另发布局数据。队友在本地移动自己的飞船（不等网络），每秒 20 次把移动、瞄准、开火、冲刺和位置发给房主；房主替队友开火。房主产生的特效和音效会记录下来在队友端重放。
- **中转**：Cloudflare Durable Objects，每个房间一个对象，只转发消息（`server/src/room.js`）。数据格式是 `var_to_bytes` 再 base64，解码时不还原对象，对方无法注入代码。
- **规则**：
  - 敌人追最近的活着的玩家，寻路以所有活着的玩家为起点。
  - 每人各有自己的武器和升级卡；升级时各自三选一，两人都选完才继续。分数共享。
  - 倒下的玩家在本波清完后复活（一半生命，2 秒无敌），出现在队友身边；两人都倒下才算结束。
  - 道具由离得最近的玩家吸取。房主青色，队友品红色。
  - 联机局不能暂停，成绩不计入排行榜。
  - 队友中途离开：房主继续单人游戏。房主离开：队友回到房间页并提示。
- v2.3 起快照里多了新 Boss 的字段（冲刺光点、空袭圈、光栅、出场倒计时），**新旧版本不能互相联机**，双方都要刷新到同一版本。
- **免费额度**：Durable Objects 免费版每天 10 万次请求，WebSocket 消息按 20 条算 1 次。按每秒约 35 条消息估算，每小时双人游戏约用 6300 次，每天大约够 15 小时。

## 11. 界面与流程

**状态**：标题 → 选武器 → 游戏中 ⇄ 暂停 / 升级界面 → 结算 →（R）游戏中 /（点击）选武器

- **标题页**：游戏名、操作说明、闪烁的「点击开始」、历史最高分，右上角是「English / 中文」语言切换按钮。
- **选武器 / 升级界面**：3 张竖卡居中排列，鼠标悬停时卡片放大、描边变亮；卡上有类别、名称、说明、等级和对应的数字键。
- **游戏中 HUD**：
  - 左上：生命格（剩 2 格以下时变红闪烁）、冲刺冷却条，下面是**构筑图标栏**：第一格是当前武器，后面按 火力 → 弹道 → 冲刺 → 生存 的顺序排列已拥有的升级，每行 6 个，边框是类别颜色，右下角数字是等级（只能拿一级的升级不显示数字）。鼠标悬停在图标上，会在图标栏右侧显示名称、等级 / 上限、类别和效果说明。再往下是超载剩余时间、屏障充能倒计时。
  - 顶部中间：当前波次，以及「升级 ◆◆◇」进度条。
  - 右上：分数、最高分、连击数；最右上角是静音按钮。
  - 底部：Boss 名字和血条（仅 Boss 存活时显示）。
  - 屏幕中间：波次开始 / 清波 / 获得升级的提示，带放大入场效果（只在游戏中和暂停时显示，不会盖住卡片和结算页）。
- **结算页**：「游戏结束」、本局分数、是否刷新最高分、波次 / 击杀数 / 存活时间，以及居中的本局构筑图标栏（同样可以悬停查看）。0.8 秒后才接受点击，防止误触。

## 13. 音效

| 命中 | 噪声方波 |
| 爆炸 / 大爆炸 | 低频噪声，0.28 秒 / 0.7 秒 |
| 受伤 | 锯齿下滑 |
| 拾取 / 开局 | 上扬正弦 |
| 冲刺 | 噪声上扬 |

## 14. 技术实现

| 文件 | 职责 |
|---|---|
| `main.gd` | 游戏状态机、武器和升级数据表、波次刷怪表、升级抽卡、全部碰撞检测（手写圆形判定和射线检测，不用物理引擎）、激光 / 爆炸 / 冲击波 / 火焰、得分、存档、地面网格绘制 |
| `scripts/player.gd` | 输入、移动、冲刺、三种武器的射击、升级等级和由此算出的属性、屏障、受伤 |
| `scripts/enemy.gd` | 10 种普通敌人和 5 个 Boss 的行为、精英词缀、外形和激光绘制 |
| `scripts/bullet.gd` | 子弹的移动和绘制，以及穿透 / 弹射 / 追踪 / 碎裂状态 |
| `scripts/pickup.gd` | 道具 |
| `scripts/fx.gd` | 粒子、光环、光束、浮动文字、火焰轨迹、刷怪预警（粒子上限 900，触屏模式 500） |
| `scripts/hud.gd` | HUD、构筑图标栏和悬停提示、升级进度条、选卡界面、语言按钮、各界面覆盖层、准星 |
| `scripts/i18n.gd` | 全部中英文文本表；`main.t(key)` 按当前语言取文字 |
| `scripts/icons.gd` | 武器和升级的矢量图标绘制 |
| `scripts/arena.gd` | 6 种场地布局、换图过渡、水晶 / 激光栅栏 / 传送带 / 传送门机关及其绘制 |
| `scripts/touch.gd` | 触屏操作：虚拟摇杆、自动瞄准和目标选择、冲刺 / 锁定 / 暂停按钮、菜单点击、竖屏提示 |
| `fonts/` | 中文字体子集和它的 OFL 许可证 |
| `tools/subset_font.py` | 重新生成中文字体子集（`tools/` 有 `.gdignore`，不会被打进游戏）。在 `i18n.gd` 里加了新汉字后要运行一次 |
| `scripts/sfx.gd` | 程序合成音效 |

- 所有节点都在运行时由代码创建，`main.tscn` 里只有根节点。
- 画面分层（从下到上）：竞技场 → 道具 → 敌人 → 玩家 → 子弹 → 特效 → HUD（CanvasLayer）。
- 一帧内新生成的敌人和子弹（地雷、小怪、碎片、Boss 弹幕）先放进待加入列表，帧末统一并入，避免在遍历列表时修改它。
- 网页导出为单线程版本，不需要跨域隔离响应头，可以直接托管在 GitHub Pages。

## 15. 已知限制

- 手机上整个 1280 × 720 画面按比例缩小（横屏手机上大约缩到一半），HUD 小字和卡片说明偏小，还没有为手机单独放大界面。
- iPhone Safari 不支持网页全屏，浏览器的地址栏和工具栏会占掉一些屏幕空间；只能「添加到主屏幕」后从桌面图标打开来获得全屏。
- 3 个新 Boss（v2.3）只经过自动测试，没有真人试玩，数值可能偏难或偏易。
- 只有英文和简体中文；新增中文文字后需要重新生成字体子集，否则新字会显示成方块。
- 没有背景音乐，没有音量设置。
- 升级数值和敌人强度还没经过大量真人试玩，平衡性需要根据实际手感再调。
- 网页版首次加载约 40 MB（主要是 Godot 引擎本体）。

## 16. 后续规划（尚未实现）

按优先级排序：

1. **背景音乐**：合成器风格循环曲，Boss 战时切换曲目；加音量设置。
2. **击败 Boss 额外奖励一张升级卡**：可选，用来补偿升级间隔拉长后后期的成长。
3. **平衡调整**：根据试玩调整升级数值、精英比例和后期波次强度；考虑加入升级之间的联动（例如「弹射 + 碎裂」的专属进化）。
4. **更多敌人**：自爆兵（接近后延时爆炸）、正面护盾兵（需要绕后或用弹射打）。
5. **局外成长**：解锁新武器（如榴弹、回旋镖）和起始升级，增加长期目标。
6. **最终命名**：候选有 Gridlock 锁格、Pulse Core 脉冲核心、Neon Siege 霓虹围城等，尚未决定。
